
# Customer Churn Prediction

An end-to-end machine learning project that predicts
whether a customer is likely to leave a subscription service.

## Objectives
- Explore and understand customer data
- Build a classification model
- Evaluate model performance
- Create a reusable prediction pipeline
- Expose predictions through an API
- Containerize the application using Docker

## Tech Stack
- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- FastAPI
- Docker
- Git and GitHub
